MAGIC MIRROR

An avatar capable of conversation and multi-agent processing set to handle general queries, weather data, and company data.

Utilising Hedra, OpenAI, and Liveki, this model showcases highly-accurate lipsyncing capabilities with a realistic model.

Installation

1. **Install Python 3.13**  
   Download and install from the [official site](https://www.python.org/downloads/release/python-3114/).  
   Make sure to check **“Add Python to PATH”** during setup.

4. Clone this repository
    git clone https://github.com/your-org/Hedra-Avatar-POC.git
    cd facial-recognition

5. Create a virtual environment
    python -m venv venv

6. Activate the virtual environment
    PowerShell 
    .\venv\Scripts\Activate.ps1
    Command Prompt 
    .\venv\Scripts\activate.bat

7. Install Python dependencies
    pip install --upgrade pip
    pip install -r requirements.txt

##Usage

Run the application
    python agent.py dev
